# F1 для фанатов

Локально: `npm install`, затем `npm run dev`, сайт на http://localhost:3000

Хостинг (Render):
1. Загрузите папку в репозиторий на GitHub.
2. На render.com: New, Blueprint, выберите репозиторий, Apply.
3. Откройте выданную ссылку https://...onrender.com.

Telegram: в @BotFather команда /newapp (или Bot Settings, Menu Button) и ссылка из шага 3.
