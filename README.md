# F1 Dashboard 2026

Мобильное веб-приложение / Telegram Mini App на Node.js + Express. Визуальный стиль сохраняет тёмный гоночный интерфейс исходного проекта, но вместо вручную прописанных таблиц использует API.

## Что подключено

- **Jolpica F1 (Ergast-compatible API)** — календарь, результаты и чемпионатные зачёты.
- **OpenF1** — список сессий, исторические позиции, классификация, шины/стинты, круги, погода и Race Control, если эти данные доступны.
- **BBC Sport F1 RSS** — новостные заголовки и ссылки на первоисточник.

### Важное ограничение бесплатного режима

OpenF1 указывает, что исторические данные с 2023 года доступны бесплатно без авторизации, а real-time data требует платной подписки. Поэтому вкладка Live в этой версии — **архив сессий**, а не обещание прямого эфира. Приложение не генерирует фиктивные позиции или очки, если источник не вернул данные.

## Запуск локально

Требуется Node.js 18 или новее.

```bash
npm install
cp .env.example .env
npm start
```

Откройте http://localhost:3000

Для разработки с автоматическим перезапуском:

```bash
npm run dev
```

## API приложения

- `GET /api/health`
- `GET /api/schedule`
- `GET /api/standings?season=2026`
- `GET /api/sessions?year=2026`
- `GET /api/session/:sessionKey`
- `GET /api/news`

Сервер кеширует ответы, чтобы не перегружать публичные API. Для Jolpica неавторизованный доступ ограничен (в документации указан burst limit 4 запроса/сек и 500 запросов/час); кэширование важно.

## Публикация как Telegram Mini App

1. Разместите проект на HTTPS-хостинге (например, Render, Railway или VPS).
2. Установите публичный URL в настройках бота через BotFather → Menu Button / Mini Apps.
3. Убедитесь, что сервер доступен по HTTPS.
4. Откройте приложение через кнопку меню Telegram.

Telegram Web App SDK уже подключён. Для работы в обычном браузере Telegram не требуется.
